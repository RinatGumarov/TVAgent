# Chrome Web Store submission packet

This directory contains material for the Chrome Web Store Developer Dashboard.
It is not part of the extension ZIP.

- `listing.md` — summary, detailed description and single-purpose statement.
- `privacy-fields.md` — permission justifications, data categories and remote-code declaration.
- `reviewer-notes.md` — reproducible review path and the fixed-tool explanation.
- `submission-checklist.md` — verified local state versus manual dashboard/browser work.
- `assets/icon128-store.png` — 128×128 store icon with transparent padding.
- `assets/small-promo-440x280.png` — 440×280 small promotional tile.
- `assets/promo-source.png` — generated full-resolution source for the promo tile.

Do not place API keys, TradingView credentials or reviewer-only secrets in this
repository. If Google requests credentials, provide temporary, revocable values
only through the Developer Dashboard's Test instructions field.
